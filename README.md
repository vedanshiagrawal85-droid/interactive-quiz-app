# Interactive Quiz Application

A responsive, dynamic web-based Quiz Application built with modern HTML5, CSS3, and JavaScript (ES6+).

## Features
- **Dynamic Question Engine**: Automatically advances questions and scores answers in real time.
- **Immediate Feedback**: Highlights correct and incorrect selections with visual indicators.
- **Score Calculation & Summary**: Displays final score percentage and performance badge.
- **Responsive Design**: Flawless experience on mobile, tablet, and desktop screens.

## Quick Start
Simply open `index.html` in any web browser to run the quiz locally!
